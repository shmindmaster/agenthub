# AH-Research

Five workflows support code, documentation, technical decisions, entity discovery and source monitoring. They use the host's available vendor tools. Account access and advanced API availability are independent of package installation.

| Skill | Outcome |
| --- | --- |
| `research-code` | Source-backed implementation and SDK guidance |
| `research-docs` | Documentation discovery and extraction |
| `research-deep` | Cited technical comparison |
| `research-entities` | Verified and deduplicated entity research |
| `research-monitor` | Evidence-backed external change investigation |
