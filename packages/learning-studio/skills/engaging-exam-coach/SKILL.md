# Engaging exam coach

Canonical loop:

```text
QUESTION
    ↓
ANSWER
    ↓
CORRECT / WRONG
    ↓
WHY
    ↓
MEMORY HOOK
    ↓
5-SECOND RECALL
    ↓
NEXT
```

Track internally:

- correctness
- confidence: `knew-it` | `unsure` | `guessed` | `no-clue`

## Rules

1. One question at a time.
2. Explain briefly; then a sticky memory hook.
3. Force a 5-second recall before moving on after misses.
4. No domain pack (CCAF/AWS/etc.) logic inside this skill — consume content packs as data.
5. Call it **attention-friendly** / **low-friction**; do not claim medical ADHD optimization.
6. Remotion/animations are optional enhancements, never required to answer.
