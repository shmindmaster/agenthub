# AH-Railway

Manage Railway projects, services and deployments through Railway's hosted server, for hosts whose only Railway plugin carries an auto-approve hook or that have none. Remote only: no local process, no stored key, no hooks.

A thin wrapper: one skill and one server, no hooks. Hosts with a clean native plugin for this service use that instead. `registry/mcps.json` records which plugin owns the server on each host.
