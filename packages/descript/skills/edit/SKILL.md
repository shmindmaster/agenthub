# Descript

The plugin connects to Descript's hosted MCP server. The host asks you to sign in once.

## Order of work

1. Inspect the project before editing it, and reuse an existing publish link rather than publishing again.
2. Ask for the edit in plain words. Descript's editor, Agent Underlord, carries it out.
3. Long jobs return a job id. Wait on that job, then show the link it returns.

## Rules

- Ask before publishing or sharing. Edits and media generation can spend Descript credits, so state that before a large job.
- Do not add burned-in or default captions. Captions stay in a sidecar file.
