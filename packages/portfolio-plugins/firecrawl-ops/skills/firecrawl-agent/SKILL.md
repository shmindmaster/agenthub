# Firecrawl Agent

Use Agent when the source set is unknown or scattered and ordinary search/map/scrape would be too manual. State the data objective, optional URL focus, fields/schema, freshness, and evidence requirements. Use `firecrawl_agent` or `firecrawl agent`; set `maxCredits`, model, output, timeout, and webhook only as needed. Poll to completion, retain the job ID and source URLs, inspect partial/error output, and cancel abandoned work. Agent output is a research input, not automatically verified truth; cross-check important claims with primary sources.
