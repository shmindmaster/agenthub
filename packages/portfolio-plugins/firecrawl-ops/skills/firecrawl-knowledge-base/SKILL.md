# Firecrawl Knowledge Base

Define the corpus boundary, audience, canonical source, allowed paths, format, chunking, metadata, and refresh policy. Map first, crawl only bounded sections, or use batch scrape for a known URL set. Retain URL, title, fetched time, content hash, extraction method, scope, and review state. Return source inventory, normalization/chunking plan, quality checks, and rerun inputs; do not treat embeddings as authorization.
