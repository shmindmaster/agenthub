# Firecrawl Dashboard Reporting

Define metric names, period, filters, unit, source, and authorized audience before interacting. Use scrape for stable content and interact for tabs, date selectors, pagination, or charts; capture the selected state and source timestamp. Return values with units and periods, evidence, calculation notes, missing data, and rerun inputs. Do not expose credentials or automate consequential changes.
