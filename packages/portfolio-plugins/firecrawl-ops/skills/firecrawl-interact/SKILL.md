# Firecrawl Interact

Scrape the page first, then use `firecrawl_interact` or `firecrawl interact` with a natural-language prompt or precise browser code. Use it for forms, tabs, pagination, login, dashboards, and reproduction steps—not for web search. Confirm authorization, use synthetic data for test input, avoid irreversible actions, capture evidence, and stop the session when finished.
