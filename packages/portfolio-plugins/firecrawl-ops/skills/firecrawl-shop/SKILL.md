# Firecrawl Shop

Define budget, location, must-have features, availability, date, and decision criteria. Search and scrape product pages or use Agent for broad discovery, then verify price, stock, specifications, seller, shipping, and return details from current sources. Return a comparison with timestamps, caveats, and recommendation logic; do not present unavailable or unverified data as current.
