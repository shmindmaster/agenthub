# Firecrawl Demo Walkthrough

Define the persona, desired outcome, starting URL, success path, and audience. Map the product, scrape supporting content, and use interact with synthetic inputs for the smallest safe happy path plus important failure states. Return step-by-step flow, observed copy/UI, friction, proof points, gaps, screenshots or URLs when available, and a short rerun recipe. Do not invent capabilities that the live product did not demonstrate.
