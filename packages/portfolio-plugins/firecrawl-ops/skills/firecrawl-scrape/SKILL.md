# Firecrawl Scrape

Use `firecrawl_scrape` or `firecrawl scrape` for known URLs. Prefer markdown and `onlyMainContent` for comprehension; request links, screenshots, change tracking, JSON, or a schema when the deliverable needs them. Use wait/actions for JS-rendered pages, redact PII when appropriate, and save outputs under `.firecrawl/`. Scrape before interact and preserve URL, fetched time, format, and extraction assumptions.
