# Firecrawl Workflows

Use this umbrella skill when the user wants a finished business, product, research, or creative deliverable rather than raw extraction or application-code integration. Infer the target, audience, scope, evidence standard, and output format. Use `../../references/workflow-routing.md`, then run independent source or competitor units in parallel when useful.

Available workflow skills:

- `firecrawl-deep-research`, `firecrawl-market-research`, `firecrawl-research-papers`
- `firecrawl-lead-research`, `firecrawl-lead-gen`, `firecrawl-company-directories`
- `firecrawl-qa`, `firecrawl-demo-walkthrough`, `firecrawl-competitive-intel`
- `firecrawl-knowledge-base`, `firecrawl-knowledge-ingest`, `firecrawl-dashboard-reporting`
- `firecrawl-seo-audit`, `firecrawl-website-design-clone`, `firecrawl-shop`

Every workflow returns a concise summary, evidence base, requested analysis/artifact, uncertainty or limitations, recommendations when useful, and rerun inputs. Keep external web evidence separate from local repository, CI, deployment, and customer/production gates.
