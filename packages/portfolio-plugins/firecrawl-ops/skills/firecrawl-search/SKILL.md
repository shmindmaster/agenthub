# Firecrawl Search

Use `firecrawl_search` or `firecrawl search` when the source URL is unknown, multiple domains must be compared, or freshness matters. Start with a small query set and limit; use `sources`, `categories`, `tbs`, location, and search-with-scrape when useful. Do not re-scrape pages already returned with full content. Save results, retain source URLs and dates, and cite claims in the final deliverable.
