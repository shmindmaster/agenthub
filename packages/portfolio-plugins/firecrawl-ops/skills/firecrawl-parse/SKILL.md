# Firecrawl Parse

Use `firecrawl_parse` or `firecrawl parse` for local documents rather than scraping a local path as a URL. Save output to `.firecrawl/`, then inspect incrementally. A remote hosted MCP cannot directly read local files; use local MCP or the documented upload handoff. Do not upload confidential, regulated, legal, customer, or production material without authorization and an explicit retention decision.
