# LinkedIn (AgentHub)

On-demand wrapper around [mcp-server-linkedin](https://github.com/stickerdaniel/linkedin-mcp-server) 4.24.0.

The MCP is **not** written into host session configs. Enable the plugin (Claude,
Codex, Grok, Cursor) or set OpenCode `mcp.linkedin.enabled` to `true` only for
an explicit LinkedIn request, then disable it.

Independent community server. Not affiliated with LinkedIn.
