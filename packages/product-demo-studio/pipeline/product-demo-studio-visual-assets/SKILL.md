# Product Visual Assets

Use generated or stock imagery only when it clarifies the viewer's problem, outcome, context, or next step. Never synthesize product UI, customer evidence, metrics, testimonials, or operational proof.

Read `../product-demo-studio/references/Visual-Asset-Guide.md` for the current model, voice, disclosure, and visual contract. Keep prompts, sources, licenses, model/provider metadata, disclosures, and output hashes in the external production workspace. Match the product's visual system, preserve text legibility and safe areas, and reject decorative assets that compete with the hero workflow.

The product repository may receive an explicitly approved product asset through normal implementation work; demo-only imagery and variants remain external.
