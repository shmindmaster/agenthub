# Episode structure

1. Cold open with a concrete problem.
2. Status quo + character objective.
3. Complication (technical + human).
4. Midpoint reversal.
5. Climax tied to a receipt/truth.
6. Takeaway the viewer can steal.

Non-series viewer-facing films reuse the same tension craft (`goal → obstacle → escalation → complication → reversal → payoff`) via Media Studio `skills/media-studio/references/story-craft.md`. Do not force those jobs to become series episodes.
