Turn an authorized audit finding or product direction into the smallest complete experience specification. Define roles, workflow, information hierarchy, states, accessibility, responsive behavior, recovery, acceptance criteria, and implementation boundaries. Reuse the product's existing design system when suitable. Write into the repository only when the user authorized a persistent artifact; otherwise return the specification in the task response.
