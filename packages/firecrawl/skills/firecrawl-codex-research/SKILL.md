# Firecrawl Research

1. Clarify the target: open web, domain, known URL, docs site, PDF, or dynamic page.
2. Use search for discovery, scrape for one known URL, map before a docs crawl, and crawl only with strict limits.
3. Use structured extraction only when a record schema is known; use agent research only when sources are unknown or scattered.
4. Cite sources and label inferences. For current information, request fresh results.

Read `../../references/tool-router.md` before selecting a tool and `../../references/security-and-compliance.md` for sensitive sources.

Never expose `FIRECRAWL_API_KEY`. Keep initial search limits at 3-5 and expand only after reviewing the first results.
