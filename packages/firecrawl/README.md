# AH-Firecrawl

Read, crawl and search websites through Firecrawl's hosted server, for hosts whose own catalog has no Firecrawl plugin. Remote only: no local process and no stored key.

The endpoint is the one Firecrawl's own Claude plugin uses. Hosts with a Firecrawl plugin that carries the server use that instead. `registry/mcps.json` records which plugin owns the server on each host.
