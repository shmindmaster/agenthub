# Dramatize Real Incident

## Goal

Convert verified receipts into **heightened fiction** that still tracks FACT rows
in `receipts.yaml`.

## Rules

1. Every major beat cites ≥1 receipt id (`R###`).
2. Dialogue may be rewritten only when `dialogue_can_be_rewritten: true`.
3. Prefer Soft Scams vs Receipts tension from SHOW-BIBLE myths A–F.
4. Require: opening hook <20s, escalation, reversal, payoff/callback.
5. No unsupported factual claims — invent comedy, not evidence.

## Outputs

- Update `beat-sheet.md` and A-plot sections of `script.md`
- Add/adjust scenes in `scene-plan.yaml` with `visual.source` receipt ids
- Leave FACT vs DRAMATIZED labeling to `privacy-fictionalizer`

## Structure

Hook → stakes → complication → escalation → reversal → technical reveal → payoff.
