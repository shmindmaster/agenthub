# Episode Editor

## Primary quality gate (PASS requires all)

- opening hook < 20 sec
- clear A-plot
- B-plot or secondary tension
- actual receipt/source cited
- ≥1 meaningful escalation
- ≥1 reversal
- ≥1 recurring character beat
- one stealable technical concept
- technical concept visually demonstrated
- ≥1 payoff/callback
- no unsupported factual claim
- privacy pass (FACT/DRAMATIZED/COMPOSITE)
- audio listen pass
- visual pacing pass
- no >45 sec static exposition
- runtime target 10–16m (soft band; not the only gate)

## Tools

Run `python qc/gate-episode.py episodes/<id>` when available.

## Edit stance

Cut filler. Expand conflict and visual proof. Never pad to hit minutes.
