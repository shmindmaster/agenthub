# Narration-led explainer shots

[Anything2Explainer](https://github.com/Vincentwei1021/anything2explainer) demonstrates building individual Remotion shots against spoken lines and reviewing the rendered picture. Media Studio uses its existing components, narration, caption pipeline and production gates. The upstream repository's [license](https://github.com/Vincentwei1021/anything2explainer/blob/main/LICENSE) requires prior authorization for commercial use of its toolkit. The workflow here uses the Media Studio implementation.

1. Read the full narration passage. Write what the viewer sees, what changes as the line is spoken and what the final state means. Give the change a spoken-word anchor. Split a passage when several changes compete for the same moment.
2. Use a dated, sourced photograph to identify a real person or place. For a product claim, show the action and resulting UI state from the authorized take. For dependencies, limits or changes over time, use `diagram`, `sequence`, `chart`, `timeline` or a drawn mechanism with `svg`. Reserve reusable footage for a return that advances the story. Provide `sourceAssetId` for derivatives of the same original and explain each return in `reuseReason`.
3. Compose directly in the kit. For an SVG group, `trace.path` takes a path in the scene's `viewBox` coordinates and draws it starting at the group's `at` anchor. `trace.durationSeconds` sets the draw time. Use the draw to follow the connection the narrator describes. Keep evidence labels legible, hold the result long enough to read and leave the captions clear.
4. Run the relevance and variety checks on the planned scenes. Review the rendered sequence with audio and captions. On a second pass, inspect the start, the change and the final state of each replacement. Remove any shot that could be moved to a different part of the film without changing its meaning. Check the standalone and embedded clocks when the same sequence serves both.
