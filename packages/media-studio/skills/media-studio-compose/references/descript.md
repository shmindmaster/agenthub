# Descript finishing

Use when an evidence-approved media-studio candidate needs Descript audio cleanup, filler-word removal, captions, or a shorter cut.

Optional finishing after truth and craft are locked. Replaces retired `product-demo-studio-descript`. Cannot repair UI defects or invent product behavior. A Descript export is a new candidate; prior approval does not transfer.

Do not apply Studio Sound to owner-voice (Sarosh) audio: it is a hosted enhancer that recolours the voice and sends owner audio to a hosted service. Use `Finish-Media.ps1` for local two-pass loudness instead. Descript MCP still cannot download a rendered MP4 without publishing.
