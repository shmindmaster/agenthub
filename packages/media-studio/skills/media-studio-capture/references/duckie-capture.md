# Duckie capture operator notes

Duckie is a client product. Its capture notes name customer tenants, tenant identifiers, sandbox hosts and collaborators, so they are private and do not live in this public repository.

Read the full note at `%LOCALAPPDATA%\AgentHub\runtime\private\media-studio\duckie-capture.md` before the first take. If it is missing on this machine, stop and ask the owner; do not reconstruct it from memory or from the product repository.

Rules that hold regardless of the note:

- The product repository is read-only input. Every override, storage state and clip lives in the external job workspace.
- Films use a synthetic tenant or a sandbox with fictional tickets and requesters. Never show real customer tickets, names or PII, and never write to a customer's systems.
- Production capture is read-only, and only on an approved sign-in route. Never copy cookies or a signed-in browser profile.
