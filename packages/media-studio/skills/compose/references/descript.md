# Descript finishing

Optional audio cleanup, filler-word removal or a shorter cut, after truth and craft are locked. It cannot repair UI defects. A Descript export is a new candidate: rerun `review`, because prior approval does not transfer. Export captions as a sidecar `.srt` only. Do not apply Studio Sound; use `Finish-Media.ps1` for loudness. The Descript MCP cannot download a rendered MP4 without publishing, so ask before publishing.
