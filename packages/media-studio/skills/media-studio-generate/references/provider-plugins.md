# Provider plugins

Load when choosing a provider. Policy does not change here: Azure first, reuse accepted assets, and a named provider runs only when a job calls for it. Every paid call stays on a governed adapter and the ledger (`../../media-studio/references/content-controls.md`). A plugin never bypasses them.

Install and credential states were checked on this machine on 2026-11-03, by key name only. "None found" means absent from `claude plugin list`, `codex plugin list` and the Claude official and community marketplaces on that date.
