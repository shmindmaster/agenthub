# Antigravity adapters

Retained surfaces:

- CLI: WinGet-managed `agy.exe`, headless-capable
- Desktop: `%LOCALAPPDATA%\Programs\antigravity\Antigravity.exe`
- IDE: `%LOCALAPPDATA%\Programs\Antigravity IDE\Antigravity IDE.exe`

Repository `AGENTS.md` is authoritative. The CLI's observed native skill path may be used; desktop/IDE plugin packaging remains discovery-required until an official specification is verified. Do not duplicate the CLI binary in a second private install directory.
