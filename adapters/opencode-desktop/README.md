# OpenCode Desktop adapter

OpenCode Desktop is a retained companion surface for the canonical OpenCode configuration.

- Executable: `%LOCALAPPDATA%\Programs\@opencode-aidesktop\OpenCode.exe`
- Shared configuration: `C:\Users\SaroshHussain\.config\opencode`
- Shared data: `C:\Users\SaroshHussain\.local\share\opencode`
- Capability ownership, skills, agents, and MCP configuration remain owned by the OpenCode adapter and central registry

Do not create a second Desktop-specific policy tree.
